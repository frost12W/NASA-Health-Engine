# Питч: что утверждаем и чем это подтверждено

## Три факта, на которых держится защита

1. **Измерение работает.** Валидный замер: 65.9 уд/мин, статус `COMPLETED_VALID`,
   POS 65.9 / CHROM 65.8 / GREEN 65.7 — расхождение 0.16 уд/мин, все гейты пройдены.
   Файл: `docs/VALIDATION.md`.
2. **Система умеет отказываться.** Два замера до этого — `INCONCLUSIVE` с указанием,
   какой гейт не прошёл (методы разошлись на 35 уд/мин; половины записи — на 10.4).
   Ложное число не выдаётся.
3. **Источники правил указаны, но пороговые оценки пока не включены.** AHA, NHS, NASA HRP перечислены как источники; в этой версии приложение не присваивает статусы здоровью и не превращает числа в оценки. Каждый показатель
   привязан к опасности, у каждой рекомендации есть источник.

## Каркас на 3 минуты

| Время | Что говорим |
|---|---|
| 0:00–0:30 | На орбите нет врача. Экипаж сам замечает изменения и решает, когда докладывать. |
| 0:30–1:15 | Что построено: дневник показателей → статус по правилам → рекомендация → тренд → контекст HRP. Офлайн. |
| 1:15–2:00 | Живой замер: 65.9 уд/мин, три метода сошлись до 0.2 — число не случайное. |
| 2:00–2:30 | Честность: при слабом сигнале — отказ с причиной, а не ложный пульс. |
| 2:30–3:00 | Дальше: сверка с прибором, датасеты PURE/UBFC. NASA даёт рамку, не данные. |

## Вопросы и ответы

| Вопрос | Ответ |
|---|---|
| Точность? | «Клиническая — не измерена. Воспроизводимость 0.16 уд/мин между методами; сверка с прибором — <цифра>». |
| Почему не ML? | «ML есть в восприятии: нейросеть MediaPipe находит лицо и зоны. Пульс считает классический метод из статьи — обучать нечего, данных для обучения нет. ML для пульса — roadmap после PURE/UBFC». |
| Чем отличается от трекера? | «Трекер даёт число. Мы — статус, действие и условие эскалации по медицинским правилам, плюс тренд и контекст миссии». |
| Где данные NASA? | «Resources челленджа — это HRP-материалы, датасетов там нет. Для валидации — PURE/UBFC, по заявке». |
| Если камера плохая? | «Откажемся и объясним почему. Дневник и правила работают без камеры». |
| Почему 15 к/с, а не 30? | «Драйвер отдаёт 15.6 при 640×480 YUY2; гейт по частоте пройден, но это ограничение железа». |

## Чего не говорим

- «медицинский прибор», «диагностика», «уровень стресса»;
- «точность ±N уд/мин» без сверки;
- «мы обучили модель» — не обучали;
- «работает на любом лице и свете» — не проверяли;
- «заменяет пульсоксиметр».

## Что подготовить к показу

1. Демо: Health Check → камера → 30 с → результат (65–70 уд/мин).
2. Резерв: запись экрана 60–90 с, если камера на сцене поведёт себя иначе.
3. Слайд с числами: 65.9 / 65.8 / 65.7 и 0.16 — крупно.
4. Слайд с отказами: два INCONCLUSIVE и причина — как доказательство зрелости.
